Air-Quality-Prediction-System
📌 Overview

The Air-Quality-Prediction-System is a machine learning–based project designed to analyze and predict air quality levels using environmental pollutant data. It uses synthetic data including PM2.5, PM10, NO₂, CO, and O₃ concentrations to calculate and predict the Air Quality Index (AQI).

🎯 Objectives

Monitor key air pollutants

Predict Air Quality Index (AQI)

Analyze pollution trends

Support environmental decision-making

📊 Dataset

The dataset contains:

Date

PM2.5

PM10

NO₂

CO

O₃

AQI (calculated target variable)

Synthetic data is generated for demonstration and testing purposes.

🛠 Technologies Used

Python

Pandas

NumPy

Scikit-learn

OpenPyXL (for Excel export)

🚀 How It Works

Generate or load air quality dataset

Preprocess data

Train machine learning model

Predict AQI

Evaluate model performance

Export results to Excel

📈 Applications

Environmental monitoring

Smart city systems

Public health analysis

Pollution control strategies

📂 Output

The system exports air quality data and predictions into an Excel file for further analysis.
